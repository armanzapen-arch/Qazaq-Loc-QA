# Qazaq Loc QA — жинақ

Қазақша/өзбекше локализациядағы жиі кездесетін ақауларды тексеретін бастапқы CLI MVP.

## Іске қосу

Python 3.10 немесе кейінгі нұсқасы қажет. Қосымша тәуелділік жоқ.

```bash
python locqa.py check --source intl_ru.arb --target intl_kk.arb --glossary glossary.csv --out report.json --html report.html --fixed intl_kk_fixed.arb
```

`--fixed` нұсқасы аударма мәтінін өздігінен өзгертпейді. ARB ішіндегі әр мәтін кілтіне `@key` метадерегіндегі `x-reviewed-by-human: false` жалаушасын қосады. Қазақтілді маман тексергеннен кейін ғана тиісті жалаушаны `true` етіп өзгертіңіз.

## Қазіргі тексерулер

Missing keys, орысша түпнұсқамен дәл сәйкестік, плейсхолдерлер, ICU жақшалары мен plural құрылымының болуы, глоссарийдегі орыс терминінің аударылмай қалуы, ықтимал ұзын UI мәтіндері, плейсхолдерден кейінгі жалғау, бірнеше жиі кездесетін орфографиялық қате, орысша/өзбекше әріп белгілері. Machine translation ескертуі эвристикалық; адам растауы міндетті. Термин бірізділігі әзірге автоматты анықталмайды.

`report.json` және `report.html` бірге жасалады. Есепте `reviewed_by_human` әдепкіде `false`.

## Шектеулер

Орфография эвристикасы тек бірнеше алдын ала енгізілген жиі қатені табады; толық емле тексергіші емес. Бұл бастапқы MVP жоба кодын немесе Flutter-ды іске қоспайды. ICU синтаксисінің тек негізгі қателерін тексереді; `flutter gen-l10n` арқылы міндетті түрде бөлек тексеру керек. `same_as_source`, тіл, машиналық аударма және ұзындық ескертулері контекстке тәуелді. Бұл құрал жасырын 100 қатенің answer key-ін алмастырмайды және олардың recall/precision бағасын есептей алмайды.

## Пакет құрамы

- `locqa.py` — CLI тексергіші.
- `glossary.csv` — бастапқы ойын терминдері.
- `methodology.md` — әдістеме және қолдағы материалдардың мәртебесі.
- `demo/` — құрал пішімін көрсетуге арналған синтетикалық мысал; Grand Mobile деректері емес.
